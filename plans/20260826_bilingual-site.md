# 英語・日本語サイトの追加

## Goal

Keep the current root page as the English site and add a fully translated Japanese site at `/ja/`, with accessible language switching between both pages.

## Steps

1. Add language metadata and EN/JA switching to the English page.
2. Add the Japanese page with translated content and correct relative asset paths.
3. Add shared styling for the language switcher and Japanese text wrapping.
4. Update sitemap and maintenance documentation.
5. Validate links, metadata, responsive markup, and static serving.
